# Tally XML Duplicate ID & Balance Cleaner 🚀
### ടാലി എക്സ്എംഎൽ ക്ലീനർ (100% Client-Side Web Tool)

Tally-യിൽ നിന്ന് XML വഴി ഡാറ്റ ഇമ്പോർട്ട് ചെയ്യുമ്പോൾ മുൻപുള്ള വൗച്ചറുകൾ Overwrite ആയി നഷ്ടപ്പെടുന്നത് തടയാനും, പാർട്ടി ലെഡ്ജർ ഓപ്പണിംഗ് ബാലൻസുകൾ സംരക്ഷിക്കാനും സഹായിക്കുന്ന ലൈറ്റ്-വെയ്റ്റ് ബ്രൗസർ ടൂൾ.

---

## ✨ പ്രധാന സവിശേഷതകൾ (Key Features)

- 🔒 **100% Client-Side & Private**: ഫയലുകൾ ഒരിടത്തേക്കും അപ്‌ലോഡ് ചെയ്യപ്പെടുന്നില്ല. നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ ബ്രൗസർ മെമ്മറിയിൽ വെച്ച് മാത്രം പ്രോസസ്സ് ചെയ്യുന്നു (Privacy Guaranteed).
- ⚡ **മിന്നൽ വേഗത (Lightning Fast)**: 18MB വലുപ്പമുള്ള DayBook ഫയൽ വെറും 0.4 സെക്കൻഡിൽ പ്രോസസ്സ് ചെയ്യും.
- 🌐 **എവിടെ നിന്നും ഉപയോഗിക്കാം**: മൊബൈൽ, ടാബ്‌ലെറ്റ്, ഓഫീസ് പിസി തുടങ്ങി ഏത് ഡിവൈസിലും ലിങ്ക് വഴി ഉപയോഗിക്കാം.
- 🛠️ **Encoding Auto-Detection**: Tally-യുടെ UTF-16LE, UTF-8 എൻകോഡിംഗുകൾ കൃത്യമായി തിരിച്ചറിഞ്ഞ് Tally-ക്ക് അനുയോജ്യമായ രീതിയിൽ തന്നെ തിരികെ നൽകുന്നു.

## 🎯 എന്തൊക്കെയാണ് ഈ ടൂൾ ക്ലീൻ ചെയ്യുന്നത്? (What Does It Clean?)

### 1. Internal Unique IDs പൂർണ്ണമായും നീക്കം ചെയ്യുന്നു:
- `<GUID>`
- `<MASTERID>`
- `<ALTERID>`
- `<VOUCHERKEY>`
- `<VOUCHERRETAINKEY>`
> **കാരണം:** ഈ ടാഗുകൾ ഫയലിൽ ഉണ്ടായാൽ, ലക്ഷ്യ കമ്പനിയിലെ മുൻപുള്ള വൗച്ചറുകൾ അവയുടെ ഐഡി പ്രകാരം മാച്ച് ആയി തിരുത്തപ്പെടാൻ (Overwrite) സാധ്യതയുണ്ട്. ഇവ ഒഴിവാക്കുന്നതിലൂടെ ഓരോ വൗച്ചറും പുതിയ എൻട്രിയായി ക്രിയേറ്റ് ആകും.

### 2. `<VOUCHER>` Header Attributes ഒഴിവാക്കുന്നു:
- `REMOTEID="..."`
- `VCHKEY="..."`
> **കാരണം:** ഈ ആട്രിബ്യൂട്ടുകൾ നീക്കം ചെയ്യുന്നതിലൂടെ വൗച്ചർ ഇമ്പോർട്ട് ചെയ്യുമ്പോൾ ടാലി അതിനെ ക്ലീൻ `ACTION="Create"` പുതിയ എൻട്രിയായി സ്വീകരിക്കുന്നു.

### 3. Opening Balance ഒഴിവാക്കൽ (Optional Checkbox):
- `<OPENINGBALANCE>` ടാഗ് നീക്കം ചെയ്യാനുള്ള ഓപ്ഷൻ.
> **കാരണം:** പാർട്ടി ലെഡ്ജറുകൾ ഇമ്പോർട്ട് ചെയ്യുമ്പോൾ പുതിയ കമ്പനിയിലുള്ള നിലവിലുള്ള ലെഡ്ജർ ഓപ്പണിംഗ് ബാലൻസുകൾ മാഞ്ഞുപോകാതിരിക്കാൻ (Overwrite ആകാതിരിക്കാൻ) സഹായിക്കുന്നു. ആവശ്യമുള്ളപ്പോൾ മാത്രം ഈ ചെക്ക്ബോക്സ് ഓൺ/ഓഫ് ചെയ്യാം.

## 📅 Month-Wise XML ക്ലീനിംഗിന് അനുയോജ്യം
- മാസങ്ങൾ തിരിച്ചുള്ള ബാക്കപ്പ് അല്ലെങ്കിൽ ഡേബുക്ക് എക്സ്പോർട്ടുകൾ (April, May, June...) ഇമ്പോർട്ട് ചെയ്യുമ്പോൾ വൗച്ചർ ക്ലാഷുകൾ ഇല്ലാതാക്കാൻ ഇത് ഏറ്റവും ഉചിതമാണ്.
- സാധാരണ ടാലി എക്സ്പോർട്ട് ഫയലുകൾ (10MB - 100MB+) വളരെ വേഗത്തിൽ ബ്രൗസറിനുള്ളിൽ തന്നെ ക്ലീൻ ചെയ്യാൻ സാധിക്കും.
- വലിയ GB ഫയലുകൾക്ക് ബ്രൗസർ മെമ്മറി ലിമിറ്റ് വന്നേക്കാം, എന്നാൽ മാസവരിയായി എക്സ്പോർട്ട് ചെയ്ത സാധാരണ ഫയലുകൾക്ക് ഇത് സുഗമമായി പ്രവർത്തിക്കും.

## 🚀 ഉപയോഗിക്കേണ്ട വിധം (How to Use)
1. `index.html` ഡബിൾ ക്ലിക്ക് ചെയ്ത് ബ്രൗസറിൽ തുറക്കുക.
2. ആവശ്യമുള്ള Cleaning Configuration ചെക്ക്ബോക്സുകൾ സെലക്ട് ചെയ്യുക.
3. ടാലിയിൽ നിന്ന് എക്സ്പോർട്ട് ചെയ്ത XML ഫയലുകൾ ഡ്രാഗ് & ഡ്രോപ്പ് ചെയ്യുക.
4. ഉടൻ തന്നെ `Cleaned_...xml` ഫയൽ ഡൗൺലോഡ് ചെയ്ത് ടാലിയിൽ (`Import Transactions`) വഴി ഇമ്പോർട്ട് ചെയ്യുക.
