# Tally XML Duplicate ID & Balance Cleaner 🚀
### ടാലി എക്സ്എംഎൽ ക്ലീനർ (100% Client-Side Web Tool)

Tally-യിൽ നിന്ന് XML വഴി ഡാറ്റ ഇമ്പോർട്ട് ചെയ്യുമ്പോൾ മുൻപുള്ള വൗച്ചറുകൾ Overwrite ആയി നഷ്ടപ്പെടുന്നത് തടയാനും, പാർട്ടി ലെഡ്ജർ ഓപ്പണിംഗ് ബാലൻസുകൾ സംരക്ഷിക്കാനും സഹായിക്കുന്ന ലൈറ്റ്-വെയ്റ്റ് ബ്രൗസർ ടൂൾ.

---

## ✨ പ്രധാന സവിശേഷതകൾ (Key Features)

- 🔒 **100% Client-Side & Private**: ഫയലുകൾ ഒരിടത്തേക്കും അപ്‌ലോഡ് ചെയ്യപ്പെടുന്നില്ല. നിങ്ങളുടെ കമ്പ്യൂട്ടറിലെ ബ്രൗസർ മെമ്മറിയിൽ വെച്ച് മാത്രം പ്രോസസ്സ് ചെയ്യുന്നു (Privacy Guaranteed).
- ⚡ **മിന്നൽ വേഗത (Lightning Fast)**: 18MB വലുപ്പമുള്ള DayBook ഫയൽ വെറും 0.4 സെക്കൻഡിൽ പ്രോസസ്സ് ചെയ്യും.
- 🌐 **എവിടെ നിന്നും ഉപയോഗിക്കാം**: മൊബൈൽ, ടാബ്‌ലെറ്റ്, ഓഫീസ് പിസി തുടങ്ങി ഏത് ഡിവൈസിലും ലിങ്ക് വഴി ഉപയോഗിക്കാം.
- 🛠️ **Encoding Auto-Detection**: Tally-യുടെ UTF-16LE, UTF-8 എൻകോഡിംഗുകൾ കൃത്യമായി തിരിച്ചറിഞ്ഞ് Tally-ക്ക് അനുയോജ്യമായ രീതിയിൽ തന്നെ തിരികെ നൽകുന്നു.

## 🚀 How to Host for Free (സൗജന്യമായി ഓൺലൈൻ ആക്കുന്ന വിധം)

### ഓപ്ഷൻ 1: GitHub Pages (ഏറ്റവും എളുപ്പം)

1. [GitHub.com](https://github.com)-ൽ പുതിയൊരു **Public Repository** ഉണ്ടാക്കുക (ഉദാ: `tally-xml-cleaner`).
2. ഈ ഫോൾഡറിലുള്ള `index.html` ഫയൽ ആ റിപ്പോസിറ്ററിയിലേക്ക് അപ്‌ലോഡ് ചെയ്യുക (അല്ലെങ്കിൽ `git push` ചെയ്യുക).
3. GitHub റിപ്പോസിറ്ററിയിലെ **Settings** &rarr; **Pages** എടുക്കുക.
4. **Branch**: `main` (അല്ലെങ്കിൽ `master`), ഫോൾഡർ: `/ (root)` നൽകി **Save** ക്ലിക്ക് ചെയ്യുക.
5. 1 മിനിറ്റിനുള്ളിൽ നിങ്ങളുടെ ലൈവ് ലിങ്ക് ലഭിക്കും:
   `https://<നിങ്ങളുടെ_username>.github.io/tally-xml-cleaner`

---

### ഓപ്ഷൻ 2: Cloudflare Pages (Drag & Drop)

1. [Cloudflare Dashboard](https://dash.cloudflare.com/)-ൽ ലോഗിൻ ചെയ്യുക.
2. **Workers & Pages** &rarr; **Create application** &rarr; **Pages** &rarr; **Upload assets** തിരഞ്ഞെടുക്കുക.
3. പ്രൊജക്റ്റിന് പേര് നൽകി (ഉദാ: `tally-cleaner`), ഈ ഫോൾഡറിലുള്ള `index.html` ഫയൽ ഡ്രാഗ് ചെയ്ത് ഡ്രോപ്പ് ചെയ്യുക.
4. **Deploy site** ക്ലിക്ക് ചെയ്യുക.
5. ഉടൻ തന്നെ `https://tally-cleaner.pages.dev` എന്ന സൗജന്യ ലൈവ് ലിങ്ക് ലഭിക്കും.
