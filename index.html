പ്രോസസ്സ് ചെയ്ത ഫയലുകൾ (Processed Files)

? ടാലിയിൽ ഇമ്പോർട്ട് ചെയ്യുമ്പോൾ ശ്രദ്ധിക്കേണ്ട കാര്യങ്ങൾ

1. നിർബന്ധമായും Backup എടുക്കുക ഇമ്പോർട്ട് ചെയ്യുന്നതിന് മുൻപായി മെയിൻ കമ്പനിയുടെ ഒരു Backup (TBK ഫയൽ) സുരക്ഷിതമായി എടുത്തു വെക്കുക.
2. Voucher Numbering മാറ്റുക Alter → Voucher Type എടുത്ത് Method of Voucher Numbering എന്നത് Automatic (Manual Override) അല്ലെങ്കിൽ Manual ആക്കുക.
3. Import Transactions ടാലിയിൽ Import → Transactions വഴി ക്ലീൻ ചെയ്ത Cleaned_...xml ഫയൽ തിരഞ്ഞെടുത്ത് ഇമ്പോർട്ട് ചെയ്യുക.

How to Host on GitHub Pages or Cloudflare Pages

ഈ ഒറ്റ index.html ഫയൽ GitHub-ലേക്ക് push ചെയ്ത് Settings → Pages എനേബിൾ ചെയ്താൽ അല്ലെങ്കിൽ Cloudflare Pages-ലേക്ക് അപ്‌ലോഡ് ചെയ്താൽ സൗജന്യമായി ലോകത്ത് എവിടെ നിന്നും ഏത് കമ്പ്യൂട്ടറിലും മൊബൈലിലും ഉപയോഗിക്കാവുന്ന ലിങ്ക് ലഭിക്കും.
